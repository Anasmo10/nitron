# ريل نايترون #3 — «التكنيك قبل المشد»

أول ريل مبني بالكامل على نظام نايترون الموحّد (`../nitron-kit/`). ثلاث لقطات (IMG_7250 · 7253 · 7260)، 13.6 ثانية مع الغلاف.

| الثانية | الكلام | الشغل |
|---|---|---|
| 0–3.0 | إذا تكنيكك غلط، مشد المعصم ما رح يفيدك | الدخلة بالكرت المفتوح. «مشد المعصم» بتتبدّل لـ«ما رح يفيدك». ستيكر المنتج وعليه ✕. الكرت بيتحوّل مباشرة لكرت اللوحة |
| 3.0–6.0 | لأن مهمته يثبّت المعصم، مو يصحّح التكنيك | لوحة المنتج: الصورة + ✓ يثبّت المعصم + ✕ يصحّح التكنيك (مشطوبة) |
| 6.0–11.3 | بس إذا ضبطت تكنيكك واخترت الوزن المناسب، هيك مشد المعصم رح يحسّن لك تمرينك | المعادلة: ✓ تكنيك صح ← ✓ الوزن المناسب ← + مشد المعصم ← «تمرين أحسن» |
| 11.3–13.5 | — | كرت النهاية: «صلّح تكنيكك… والمشد بيكمّل» + «اطلبه من نايترون» |

**ملاحظات:**
- «مو يصحّح» بالمقطع التاني: أول حرف بالصوت ملتبس بين «و» و«م». اخترت «مو» لأن النموذج حاطط فراغ بين الكلمتين، ولأن المعنى ما بيمشي غير هيك. بدها تأكيد.
- آخر نص ثانية من IMG_7260 مو واضح، فانقصت والجملة بتخلص على «تمرينك».
- **صورة المنتج:** لما توصل كملف، بتنقص وبتنحفظ `product.png` (بطاقة المنتج) و`stk_product.png` (ستيكر بحافة بيضا) بمجلد الشغل. بعدها رندر الدخلة 0–3 ولوحة المنتج 3–6 والمعادلة 9.4–11.3، ثم `06_encode.sh` و`finish.sh`. لحد هداك، المكتبة بترسم أيقونة مشد.

**التحقق:**
- التزامن: أكبر فرق 31ms.
- الصوت: −15.3 LUFS والذروة −1.4. الموسيقى 12dB تحت الكلام (بالمعيار الموحّد).
- ما في نص بمناطق أزرار إنستغرام. الإنذار الآلي بالدخلة جاي من الخلفية وحافة الكرت.
