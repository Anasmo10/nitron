# مونتاج ريل «مصر بالأرقام» — ملفات المشروع

مونتاج بسكل `video-ad-editor` من بلوجن majed-video. الطلبات كانت محكية جوّا الفيديو نفسه:

| الطلب بالفيديو | التنفيذ |
|---|---|
| «كلود حط ورايا أهرامات» | قصّ الشخص (u2net) + خلفية أهرامات مرسومة — الجملة الأولى بس (`scenes.js` ← `pyramidsBg`) |
| «حط إحصائية لعدد سكان مصر من 2018 لـ2026» | رسم بياني متحرك بأرقام الجهاز المركزي (`pop-scene.js`) |
| «قرّب الشاشة علي» | زوم 1.38 على الوجه بجملة الوضع الاقتصادي (`zoomOnMe`) |
| «صور 2016 و2018» + «صور عن تعويم العملة» | لوحة التعويم + لوحة رأس الحكمة (`floatPanel` · `hekmaPanel`) |

- الأرقام ومصادرها: `facts.md`
- الجمل اللي انقصّت من الأصل: `cut.json` · توقيت الكلمات: `a.json` / `caps.json`
- الترجمة وكابشن البوست: `egypt-reel-final.srt` · `egypt-reel-caption.txt`
- الفيديو النهائي والفيديو الأصلي مو مرفوعين هون (الريبو عام).

إعادة الرسم: انسخ الملفات لمجلد شغل فيه `src.mov` (الفيديو الأصلي)، وبعدها خطوات السكل
