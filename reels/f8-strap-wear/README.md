# ريل نايترون — «الفيغر 8 ستراب مو شادد؟ الغلط باللبس»

عشر مقاطع واتساب (17 نوفمبر 2026) صاروا ريل واحد، 18.1 ثانية + كرت النهاية (2.2 ثانية).
- 4 مقاطع حكي للكاميرا (c01–c04).
- 6 لقطات بالنادي للإيدين وهي عم تلبس الستراب وتتمرّن (c05–c10).

## الجودة

المقاطع واصلة من واتساب بدقة 576×1024، فكبّرناها كالتالي (`sr8.py`):
1. Real-ESRGAN (realesr-general-x4v3، ONNX) على كل فريم مستعمل.
2. دمج 60٪ مع 40٪ Lanczos: الصورة أحدّ، والبشرة بتضل طبيعية ومو بلاستيكية.
3. الحجم 1620×2880، وبعدين `minterpolate` لـ30 فريم، وبعدين `build_cut` بـ`"hires": 1620`.

الأفضل للمرة الجاية: يوصلنا التصوير الأصلي كملف (Document)، مو كفيديو واتساب.
